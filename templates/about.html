ABOUT THE PROJECT

Intelligent Harmful Message Detection

A machine-learning system designed to support safer digital conversations.

Project Overview

SafeText AI analyses online text and classifies it into cyberbullying, hate speech, toxic language, harassment, offensive words, threats, or normal messages. It combines text preprocessing, TF-IDF feature extraction, and Logistic Regression classification.

How it works

  1. The user enters a message.
  2. The system cleans and prepares the text.
  3. NLP converts the message into numerical features.
  4. The trained model predicts the category and confidence score.
  5. The result is stored for history and administrative reporting.
